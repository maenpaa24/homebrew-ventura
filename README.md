# homebrew-ventura

## How do I install these formulae?
`brew install maenpaa24/ventura/<formula>`

Or `brew tap maenpaa24/ventura` and then `brew install <formula>`.

Or install via URL (which will not receive updates):

```
brew install https://raw.githubusercontent.com/maenpaa24/homebrew-ventura/master/Formula/<formula>.rb
```

## Documentation
`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
